About

Aspen uses the Bootstrap framework so there are many classes and layouts we have access to when we create basic or custom pages in Aspen. Because Aspen uses a basic WYSIWYG editor, if you want to add Bootstrap elements to a page, you have to go to the code view and hand-code things like buttons or badges or to use the Bootstrap column configurations or other Bootstrap elements.

On some of the training pages we are creating for Next Search Catalog we wanted to add links to go to other resources and with Bootstrap you can turn simple links into buttons that look cool and stand out. This tool is designed to make adding a button to an Aspen basic or custom page really easy and really consistent. To get the HTML for a button, all you have to do is enter the name of the button, the URL for the link you want the button to take you to and click a few radio buttons. There are even 4 pre-defined button names, so if you are using buttons to link to resources that are consistently the same, those buttons can have the same look and feel across all the pages you use them on.

This entire project is available on Github, so if you'd like to see the source code or if you'd like to download a copy of the project and change it to suit your needs, feel free to do so.
